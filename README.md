# Juego Especial

Juego web táctil de 4 minijuegos (Sudoku, Crucigrama, Billar, Minecraft 2D) con Vite + Phaser.

```bash
npm install
npm run dev      # desarrollo (accesible desde el móvil en la misma red)
npm run build    # producción -> dist/
```

Despliegue: importar el repo en Vercel (autodetecta Vite). Plan completo en `docs/PLAN.md`.
